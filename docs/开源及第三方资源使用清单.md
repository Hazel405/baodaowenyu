## 六、与报告附录（一）表格的差异（**订正项，编辑报告时同步**）

2. **NGA CADRG 航图**：附录列为已使用资源 → 应标注 **"未采用（本包不含扫描件）"**，避免清单与实际交付不一致。

5. **OpenTopoData**：附录写"公开数据 / 按站方条款"过于模糊 → 明确为"服务端 MIT，数据源公共领域，遵守站方限速"。
6. **在线瓦片**：附录须补入 Esri World Imagery / World Street Map 两行（见本文档 #20）——仅客户端在线引用、不落盘不缓存、不随包分发，署名已内置网页页脚；与"底图零第三方瓦片**再分发**"红线一致 ✅。
