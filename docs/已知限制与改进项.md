# 已知限制与改进项

本文件随仓库发布，用于向使用者与评审如实说明系统当前的能力边界与下一步改进项。
每条均给出**现象、根因、影响范围、改进路径**，并标注是否已在评测中量化。

## 一、问答与消歧

### 1. 同名实体消歧准确率 70.7%（已量化，最高优先级改进项）

- **现象**：`eval/eval_disambig300.py` 300 题（100 组同名跨 ≥2 县市实体 × 3 句式）命中 212 题（70.7%），
  错选同名干扰项 22 题（7.3%），其余 66 题未命中；平均 18.5 s/题。
- **未命中根因分解**（逐题判定见 `eval/outputs/disambig300_2026-10-01.json`）：
  - 38 题：答案已落到目标县市，但给出的是**同县内另一个同名聚落**的乡镇与坐标（如目标为南投縣名間鄉「下埔」，答成魚池鄉「下埔」）；
  - 18 题：库内确有该记录，检索却返回空，系统按防幻觉策略回答"库内无该条目"（假阴性拒答）；
  - 10 题：答案指向其他地点。
- **根因定位**：`server/rag_server.py` 的 `q_place` 按地名匹配后**未先以目标县做空间过滤即截断返回**，
  县内村内重名属二级歧义，Top-N 截断使真值条目未进入候选。
- **改进路径**：
  1. 提问含明确县市时，先用 `ST_Within` 限定到该县再取全部同名候选，并在答案中逐条列出（预计可显著提升命中率）；
  2. 判定与检索两侧的简繁归一（现有 `S2T` 表仅覆盖高频 20 字）；
  3. 把"同县同名多结果"作为插件端可点击候选清单，交由用户在地图上二次确认——与"问答联动定位"复用同一机制。
- **口径说明**：该基准刻意把真值设为**非最大、非首个**同名条目，任何按人口排序或取首条的检索必然答错；
  公布严格下界优于换题抬分。全部 300 题输出数字与坐标**零虚构**（错选题引用的也是库内真实条目）。

### 2. 30 题问答基准 100% 的适用边界（已量化）

- 题目为五类意图（地名/人口/事件/设施/关注度）各 6 题，覆盖常见问法；未覆盖方言词源长问句、
  多跳推理（"A 的上级行政区在 1920 年属哪个街庄"）与跨表联合统计类问题。此类问题目前会走拒答分支。

### 3. 响应时延

- 问答链路平均 4.9 s/题（QA30）～18.5 s/题（消歧题面更长、候选更多），瓶颈在本地 qwen3:8b 生成而非检索（检索为毫秒级）。
- 改进：对纯数值型问题走"免生成"直返模板；已配置 `keep_alive=30m` 与启动预热以消除冷启动。

## 二、数据覆盖与口径

| 项 | 现状 | 影响 | 改进 |
| --- | --- | --- | --- |
| OSM `admin_level=8` 乡镇面 | 204/368（约 55%） | 乡镇级聚合与村级归属出现缺口，是消歧假阴性的来源之一 | 错峰重采 + 用乡镇界公开资料补采，缺口在答案中显式提示 |
| GDELT 事件 | 双周采样 15,295 条，非全量 | 事件计数为抽样口径 | 答案固定标注"收录时间范围/采样方式"；可切换 GDELT 2.0 |
| 人口 | WorldPop 2020 估算与 GeoNames 点值双口径，与户籍口径约 3% 差异 | 数字与官方统计不完全一致 | 双口径并列标注，不制造虚假精确 |
| 电厂容量 | OSM `capacity` 缺失部分记录 | 容量求和被低估 | 缺失即答"字段缺失"，不做插值 |
| GeoNames `admin1/admin2` | 实为代码（"03"/"TPQ"）而非地名 | 不能直接给中文县市名 | 已改为点几何对行政面 `ST_Within` 反查 + 英汉对照（已入管线） |

## 三、底图与历史舆图

- 参赛版底图为自渲 XYZ 金字塔（街道 z0–13 共 20,854 张、地形晕渲 z0–12 共 2,853 张，合计 23,707 张；另有山体阴影中间产品 2,853 张不随包分发），**不含任何 Esri/Bing/Google 瓦片**。
- 街道瓦片在低层级（全岛视角）海面填充不一致，会出现色块边界：已按比例尺设置可见性阈值（分母 >32 万不绘制），
  全岛视角改用晕渲底图。
- 卫星影像层受离线环境限制列为摆渡扩展项（Sentinel-2 CC-BY / NASA Blue Marble 公共领域）。
- 历史舆图（清季、日治实测地形图 1898–1904、1947、2020）已完成获取清单与权利登记，
  扫描件摆渡入库后按同一管线切片，"较"工作台的卷帘机制已就绪。

## 四、QGIS 插件

- 图层工作台为"勾选即增删"实时模式；加载图层时按画布 CRS 做 4326↔3857 变换后再 `setExtent`，
  规避 XYZ 底图与矢量图层坐标系不一致导致的空白画布。
- 制图模板（A4 专题图）为半自动：图例与比例环已模板化，指北针与图廓注记按主题手工微调。
- 待办：图例联动、标注冲突优化（北部都会区聚落注记密集）、暖色人口色带的图例分级标签。

## 五、评测复现方式

```bash
# 依赖：PostgreSQL+PostGIS(:5433, db=tw)、瓦片服务(:8090)、RAG 服务(:8600)、Ollama qwen3:8b
python eval/eval_qa30.py            # 30 题问答基准 → eval/outputs/eval_qa30_<date>.json
python eval/eval_disambig300.py     # 300 题同名消歧 → eval/outputs/disambig300_<date>.json
```

两个脚本的判定规则写在文件头注释中，逐题 `verdict` 与答案摘要保留在输出 JSON 内，便于第三方复核与错误分析。
