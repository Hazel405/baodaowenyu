# 宝岛文舆 · 用户试用量表（10 人实测周 10.6–10.9）

> 用途：技术报告第五章"验证结果"用户试用证据；佐证材料附件。
> 对象：相关师生 ≥10 人（匿名编号 U01–U10，不收集姓名院校）。
> 方式：现场/远程各 15 分钟，完成 3 个任务 + 填量表。量表数据汇总后以 JSON 存 eval/outputs/。

## 任务设置（每题完成后记录 成功/失败 + 用时）
- T1 检索：在"询"面板提问"斗六地名有什么来历？"，确认答案含来历与所在县市；
- T2 消歧：提问**"三和在哪里？"**（★地名放句首；实测"云林县三和在哪里？"会答不出）。确认答案并列 3 处同名聚落（云林莿桐/彰化福興/台东太麻里）并在地图联动高亮；
- T3 制图/分析：在"析"面板选南投县点"分区统计"，说出平均坡度与最高点数值。

## 量表（1–5 分：1 非常不同意 → 5 非常同意）
| # | 条目 | 维度 |
|---|---|---|
| Q1 | 我能在 1 分钟内得到可信的答案 | 易用性 |
| Q2 | 答案给出的来源让我敢于引用到作业/研究中 | 信任度（核心） |
| Q3 | 与直接问通用大模型相比，本系统答案更可靠 | 相对价值 |
| Q4 | 地图联动（点击来源/定位）帮助我理解答案 | 交互设计 |
| Q5 | 历史舆图叠合对地名/乡土学习有价值 | 场景价值 |
| Q6 | 我愿意向地理教学场景推荐本系统 | 推荐意愿 |
| Q7 | 界面术语我能理解（如有不懂请写出） | 学习成本 |

## 开放题
- O1 你最想问但系统答不了的问题？（收集 bad case）
- O2 与百度地图/谷歌地球相比，这个工具的独特价值一句话概括？（对应评委必问）

## 记录模板（每人一行）
编号, 专业, T1成/败+秒, T2成/败+秒, T3成/败+秒, Q1..Q7, O1, O2

## 汇总输出
- 任务成功率、量表均值±标准差、O2 高频关键词；
- 存 eval/outputs/试用量表汇总_<date>.json + 原始记录截图（脱敏）。
