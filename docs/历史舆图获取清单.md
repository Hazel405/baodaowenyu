## 摆渡验收清单（10.5 功能冻结前）
1. 每幅 ≥8 个 GCP，纠正 RMSE ≤ 图上 1mm（二十万分一 → 地面 ≤200m 可接受，堡图 ≤25m 佳）；
2. 图廓完整、无遮标水印；扫描分辨率 ≥300dpi；
3. registry.csv 行更新（来源 URL + 下载日期 + 授权摘录）；
4. 切片后在 demo_contest"较"工作台卷帘对比无系统性偏移。

## 若摆渡失败（降级预案）
用本机已有 JNC/GNC 1998 航图（公共领域、已配准）做"历史底图"时点之一，配合 OSM 现势图，形成"1998 vs 当代"两时点对比 + 地名溯源（GeoNames 别名含旧称），叙事仍成立，只是少一层百年纵深。
