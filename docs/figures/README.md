## 一、地形工序图

### 1. `fig_terrain_flow.png` · DEM → 色带 → 瓦片 三级工序对照

**图注（3 条，必需）**：

1. **深绿色为海域**（色带 0m 基线样式）——非渲染错误。
   依据 `basemap/dem_ramp.txt` 第 1 行 `0 0 90 0`（0m → 绿）；与交付瓦片台湾海峡抽测像素
   `(6,94,5)` **同色**，属**基线样式，非缺陷**。
2. **图为独立复现环境产出**，色带断点与交付基线**略有差异**；**交付瓦片以仓库内基线为准**。
   （复现环境断点 2300 vs 基线 2500 → 像素级与图例都会对不上，故**复现产物不替换交付 `basemap/`**。）
3. 「高程倒错」面板为 **问题复现示意，非成品产出**。
   （该面板展示的是重建过程中出现的错误状态，用于说明问题发现与解决，不代表最终渲染效果。）

### 2. `fig_terrain_ramp.png` · 色带图例

**图注**：色带断点取自独立复现环境（最高断点 2300）；
交付基线最高断点为 **2500**（`2500 140 70 55`），**图例以基线为准**。

## 三、瓦片资产口径（硬约束）

| 项 | 值 | 说明 |
|---|---|---|
| 交付基线 street | **20,854** 张 | 以仓库内 `basemap/street/` 为准，**不要覆盖** |
| 交付基线 terrain | **2,853** 张 | 以仓库内 `basemap/terrain/` 为准，**不要覆盖** |
| 独立复现地形重建 | 2,853 张 | 作为**可复现性证明**留档，**不进交付 `basemap/`** |
| 色带断点 | 复现环境 2300 / 基线 **2500** | **不一致，故不可替换** |

> 独立复现瓦片重建成果的价值是「**可复现性证明**」——证明交付瓦片可由仓库内脚本
> 从原始数据完整重建，正好对应评分项「版本迭代、问题解决过程」。
