## 制作备忘
- 分辨率 1920×1080，30fps；录 OBS；转码 H.264 CRF23 压到 ≤300MB；
- **瓦片缩放上限（2026-10-06 实测）**：自产瓦片 `street` 只到 **z13**（≈1:6.5 万）、`terrain` 到 **z12**；视图比例尺**不要小于 1:80000**，否则超出瓦片范围会**白屏**（实测设 1:2 万即全白）。镜 2 起始比例尺取 **1:100000** 最稳。
- 镜 2 不要点「＋注入自产底图」：演示工程 `demo_project.qgz` 已含「街道图 / 地形晕渲」两个 XYZ 图层，重复注入会叠加图层并强制把视图跳回全岛，打断缩放过程。
- 敏感自查：录前关闭无关窗口（微信/浏览器书签/文件管理器地址栏）；视频元数据清空作者字段；
- 兜底：QGIS 现场崩溃 → 用已生成的 docs/figures 五图 + demo_contest 网页录屏替代镜头 2/3/4。
