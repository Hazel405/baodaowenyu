（`eval/outputs/` 是脚本运行时的工作输出目录，不入库；本目录是定稿快照。）

## 关于对照组（裸模型消融）的脱敏说明

对照组为「同一模型 `qwen3:8b`、不带任何检索、直问同样 30 题」。
该组输出由模型自发产生，**含非民用设施与涉政表述**（这正是「无检索增强会失控」的实证之一）。
按本项目的内容合规口径，本目录**只保留脱敏后的逐题判定表**（`裸模型消融_逐题判定_20261008.csv`，
已把不可溯源的库外实体与涉政片段脱敏为「（已脱敏）」），原始逐字输出不随仓库分发。

## 人口口径（重要）

自 2026-10-08 起，本作品对外的人口数字统一采用 **WorldPop 2020 县市分区口径**
（`tw_demo_countypop` / `tw_demo_townpop`，与人口图层、随包人口三表同源）。

早期结果中曾混入 `tw.gaz_tw.population`（GeoNames 城市点 / 都会区口径，如 `Taipei` 的 PPLC 值为都会区合计），
两套口径不可同屏混用；系统问答侧已同步统一（仓库提交 `071b351`）。
逐题表中的「库内真值」「真值口径」两列已按统一口径标注。

